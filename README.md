# ⚽ Мини-футбол

Браузерная мини-игра в футбол с видом сверху (2D). Игроки — кружки, мяч в два раза меньше игроков.
Играйте против ботов, с ботами в своей команде или вдвоём на одной клавиатуре.

**Играть:** https://mogger112.github.io/mini-football/

## Управление

### Компьютер
- **P1 (синие):** `WASD` — бег
- **Зажать ЛКМ** — держать мяч и набирать силу удара, **отпустить** — удар в сторону курсора
- **ПКМ** или `Shift` — держать (вести) мяч, `Пробел` — быстрый удар
- **P2 (красные):** стрелки — бег, `Enter` — удар, правый `Shift` — держать мяч
- `B` — боты вкл/выкл, `P`/`Esc` — пауза, `R` — новый матч

### Телефон
- Джойстик слева — бег (коснитесь в любом месте левой половины экрана)
- **Удар** — зажать, чтобы держать мяч и набрать силу, отпустить — удар
- **Держать** — вести мяч
- ⚙ — настройки (боты, сложность, время), ⛶ — во весь экран
- Лучше держать телефон горизонтально
- **Android:** игра сама переходит в полный экран после нажатия «Играть»
- **iPhone:** Safari не умеет открывать сайты на весь экран — нажмите «Поделиться» → «На экран Домой», и игра будет запускаться с иконки на весь экран

### Полный экран на ПК
- Кнопка ⛶ в правом верхнем углу или клавиша `F`

## Игра по сети 🌐
Играть вместе можно с любых устройств — ПК и телефоны вперемешку.
1. Один игрок открывает меню (⚙) → **Создать комнату** и получает код из 4 символов.
2. Остальные открывают игру, вводят код, выбирают команду и нажимают **Войти**
   (или открывают ссылку-приглашение из кнопки «🔗 Пригласить»).
3. Создатель комнаты нажимает «Играть». Боты заполняют свободные места, их число и сложность задаёт создатель.

Матч считается на устройстве создателя комнаты — ему нельзя сворачивать игру.
Соединение прямое (WebRTC), для установки связи нужен интернет; в одной Wi-Fi сети работает быстрее всего.

## Настройки
- Количество ботов в каждой команде (0–5) и общий выключатель ботов
- Сложность: лёгкая / средняя / сложная
- Время матча: 1, 2, 3, 5 минут или без лимита
